# Prompts das aulas

Prompts que foram usados em cada aula gravada do curso, copiados dos roteiros (Google Drive, pasta MATERIAL AUTORAL). O texto de cada prompt está exatamente como aparece no roteiro, para você poder repetir a aula na sua máquina.

A maioria dos prompts foi enviada ao **Claude Code**, no terminal, na raiz do repositório. As exceções aparecem indicadas no próprio arquivo: os prompts da 4.1 que foram para o **Claude Design** (`claude.ai/design`) e a pergunta em linguagem natural da 3.4 que chama a tool MCP `perguntar`.
